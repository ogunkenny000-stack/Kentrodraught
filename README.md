# Kentro downloadable deployment package

This branch distributes the latest uploaded app with rebuilt assets for the migrated Supabase project and financial switches enabled. The repository main branch is unchanged.

Download Kentro-migration-candidate.zip and verify it using the accompanying SHA-256 file. Private keys, deployment settings and account backups are excluded.

This is a deployment candidate, not a live website update. Review Kentro-DEPLOYMENT.md inside the ZIP before switching traffic. Real bank transfers and payouts have not been tested.
